# Synthetic Demonstration Dataset

This dataset contains 33 artificially generated CI/CD workflow runs.
It is not collected from iSign, GitHub Actions, or any real company.

The dataset is provided only to demonstrate the existing Python
IQR and Isolation Forest implementations.

Runs 9, 24 and 31 contain deliberately increased timing values.
These are synthetic test scenarios, not verified production anomalies.

Results from this dataset must not be presented as thesis findings.
